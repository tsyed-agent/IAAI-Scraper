# AGENTS.md

## Cursor Cloud specific instructions

### Where the code lives (important)
The application code currently lives **only on the branch
`cursor/iaai-ontario-research-and-plan-38cd`**. The `main` branch is an empty
placeholder (just `README.md`). A future agent must be on that branch (or have
it merged into `main`) for any of the commands below to exist. The update
script is guarded so it is a no-op when `requirements.txt` is absent.

### Project
`IAAI-Scraper` — a Python scraper for IAA/IAAI Canada (`https://ca.iaai.com/`)
auction lots, scoped to Ontario. It crawls lot data (Playwright headless
Chromium to clear the Imperva/Incapsula challenge), stores it in SQLite, and
serves it via a read-only FastAPI. It is a single Python package
(`iaai_scraper`) — there is no separate frontend/backend split.

### Running things (activate the venv first: `. .venv/bin/activate`)
Commands are documented in `README.md`; the entrypoints are:
- Tests (offline, no network): `python -m pytest`  (`pytest` is a dev-only dep,
  not listed in `requirements.txt`; the update script installs it).
- Crawl: `python -m iaai_scraper.cli crawl --max-pages 3 -v` (use a small
  `--max-pages` for a quick test; a full crawl is ~52 pages / ~5k Canada lots).
- DB stats: `python -m iaai_scraper.cli stats`
- API: `python -m iaai_scraper.cli serve` (serves on `127.0.0.1:8000`; Swagger
  UI at `/docs`). The API only reads; the crawler is the only writer, so run a
  crawl first or the DB/endpoints will be empty.

### Non-obvious notes
- The live crawl **does work from this VM** — it clears the Imperva challenge
  from a datacenter IP without a proxy (verified during setup). No `IAAI_PROXY`
  is required for small test crawls.
- Output is written to `data/` (`data/iaai_ontario.db` + gzipped raw JSONL) and
  is git-ignored — it is regenerated by crawling, never committed.
- There is no configured linter/formatter (no ruff/flake8/black config); use
  `python -m py_compile iaai_scraper/*.py tests/*.py` as a basic check.
- Playwright OS libraries were installed once via
  `playwright install --with-deps chromium` (persisted in the VM snapshot); the
  update script only refreshes the browser binary, not the system libs.
